# How to repin a lockfile to another interpreter or platform

*How-to guide, for an engineer who needs a hash-locked lockfile to
install on a new interpreter, runtime or platform without changing any
package version.*

This guide shows you how to land a same-version repin with the
`repin-lockfile` workflow: the lockfile regenerated by the tool that
made it, every version proven unchanged, and a hash-enforced install on
the new target. If a package has to move to another version, use
[how to upgrade a dependency or toolchain](how-to-upgrade-a-dependency-or-toolchain.md)
first.

1. Find the lockfile path and name the target exactly, for example an
   interpreter minor version, a runtime release or an OS and CPU pair.
2. Decide whether the old target must stay installable. If you are not
   sure, leave `keep` out and the plan decides from what still uses it.
3. Ask Claude:

   ```
   Run the devops-engineer repin-lockfile workflow with
   args { lockfile: "<path>", target: "<target>", why: "<reason>" }
   ```

   If your session must not spawn agents, add
   `run: { mode: "inline" }`.
4. Read the plan the workflow logs. Check that `command` is how the file
   is really generated, that `references` lists every pipeline step or
   image that names the old target, and that `verify` enforces hashes.
5. When it finishes, read `decision`:
   - `ready-for-review`: the draft PR on `branch` shows "versions
     unchanged: N of N" and the target install run. For a work package,
     run engineering-practices deliver-package with
     `{ wp: "<the package>", prior: <the whole result> }`. With no work
     package, hand it to the code reviewer, then land it with
     engineering-practices land-pr. `next` gives both commands.
   - `blocked` on a missing distribution or a version change: that
     package needs an upgrade. Run upgrade-dependency for it, then run
     this workflow again.
   - `blocked` on anything else: read `open`, fix, and rerun with
     `run.from` and the returned `results`.

See the [repin-lockfile reference](../reference/workflow-repin-lockfile.md)
for all arguments and outputs.
