# License compliance

- Keep a list of every dependency and asset source with its license;
  ship the notices each license requires in-app and in the release.
- Meet the project license's own duties (for copyleft: published source
  for every shipped build, license text included, linked from the store
  page and in-app).
- Credits: one source file listing the people and works to credit, used
  by both the in-game credits screen and the project website (built by
  the `frontend-web-developer` role).
- Make every release's source and notices available where the website
  and store pages can link to them.
